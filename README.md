# Card CRM Demo

Минимальная демо-версия под ТЗ:

- таблица карточек с ценой `35 000 сум`;
- простая CRM с воронкой;
- блок рисков и контроля;
- без сложного backend.

## Как открыть

Открой `index.html` в браузере.

## Что внутри

- таблица карточек;
- базовые показатели;
- колонка CRM по статусам;
- простой визуальный прототип для согласования.
